# Como funciona este cofre

- **00-Entrada**: tudo chega aqui primeiro. {{ASSISTENTE}} organiza depois.
- **01-Projetos**: o que tem prazo e fim (um lançamento, uma viagem, uma reforma).
- **02-Areas**: o que você cuida sempre, sem data de fim (saúde, finanças, família, empresa, igreja).
- **03-Recursos**: assuntos e referências (cursos, ideias, livros, ferramentas).
- **04-Arquivo**: projetos concluídos e coisas que pararam de importar. Nada é apagado.
- **05-Diario**: revisões semanais e notas do dia.
- **_modelos**: modelos de nota. **_anexos**: arquivos, fotos, PDFs e áudios.

Cada nota tem título, data, etiquetas e ligações [[assim]] para notas parecidas.
Para mandar algo: fale com {{ASSISTENTE}} ("anota isso", "guarda no segundo cérebro") ou só mande o arquivo.

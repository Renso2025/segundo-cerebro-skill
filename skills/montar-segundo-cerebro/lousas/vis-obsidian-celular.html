Segundo cérebro no celular

Uns 10 minutos. Faça na ordem.

  1. 1. Criar o cofre

    Na tela do print, escolha Neste dispositivo. Dê o nome Segundo Cérebro e toque em Criar.

  2. 2. Instalar o plugin Git

    Engrenagem ⚙️ › Plugins da comunidade › Ativar › Procurar. Busque Git (autor Vinzent). Toque em Instalar e depois em Ativar.

  3. 3. Criar a chave do celular no GitHub

    No navegador, abra o link 1 abaixo.
    • Token name: Obsidian
    • Expiration: 1 ano
    • Repository access: Only select › {{REPO}}
    • Permissions › Contents: Read and write
    Toque em Generate e copie a chave. Ela aparece uma vez só, e ninguém mais precisa vê-la (nem eu).

  4. 4. Pôr a chave no plugin

    Engrenagem ⚙️ › Git (no fim da lista), seção Authentication/Commit author:
    • Username: {{USUARIO}}
    • Password/Personal access token: cole a chave
    • Author name e e-mail: os seus

  5. 5. Puxar as notas

    Deslize o dedo para baixo na nota (ou toque no ícone ⌘) para abrir os comandos. Digite clone e escolha Git: Clone an existing remote repo. Cole o link 2. Quando ele perguntar a pasta, escolha Vault Root. Na profundidade (depth), deixe em branco. No fim, feche e abra o Obsidian de novo.

  6. 6. Sincronizar sozinho

    Engrenagem ⚙️ › Git:
    • ligue Pull on startup;
    • ponha 10 em Auto commit-and-sync interval.
